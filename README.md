# Bilawal Homoeopathic Clinic website

Website for Bilawal Homoeopathic Clinic, Burewala, Punjab, Pakistan.

- **Pages:** Home, About (doctors), Treatments, Offers, Reviews, Blog, Appointment, Contact.
- **Built with:** plain HTML, CSS and JavaScript. No framework and no server. Hosted on GitHub Pages.
- **Folders:** `css` styles, `js` scripts and clinic data, `img` and `media` pictures and videos, `vendor` the slider library.
- **Manager pages:** the clinic's doctor updates offers, blog posts, timings and reviews through the sign-in protected manager pages.

No passwords or private keys are stored in this repository.
