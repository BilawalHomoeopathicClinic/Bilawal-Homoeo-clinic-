Timings manager

How this works
  1. Set the clinic's opening hours and tick the days each doctor is available.
  2. Press Download timings.js.
  3. Replace the file js/timings.js in the website folder with the downloaded one, and upload the website again.
The new times then show in the footer, on the Contact and Appointment pages and on each doctor's card.
